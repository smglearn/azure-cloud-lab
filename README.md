# Azure Cloud Lab (AZ-900 & AZ-104)

Central repository for cloud architecture templates, Entra ID access control patterns, and certification study matrices.

## Workspace Layout
- `notes/az-900/` — Cloud concepts, Azure architecture components, security, and governance fundamentals.
- `notes/az-104/` — Azure Administrator implementation: Entra ID, virtual networking, compute, storage, and monitoring.
- `bicep/` — Infrastructure as Code (IaC) deployment definitions.
- `entra-id/` — RBAC role definitions, conditional access policies, and identity audit logs.
- `scripts/` — Automated Azure CLI (`az`) and PowerShell management scripts.
